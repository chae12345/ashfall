# 검증 기록

환경: Windows, Unity 6000.6.9f1 (8c45277fb9c5).

- Unity 프로젝트 임포트 및 Core/Runtime/Editor 어셈블리 컴파일 성공.
- `Ashfall.Editor.Validation.Run`: **797,812개 조건 검사 통과**.
- 100개 지도 시드: 재현성, 유량 보존, 하류 높이, 배수 연결·비순환, 주민 시작 위치, 습격자 접근 가능성.
- 이동·자세: 1칸/2칸 점유, 벽/사람/경계 충돌, 회전 차단, 다리 횡단, 동적 장애물.
- 전투·경제: 사선, 탄약, 피해/사망 보상, 회수 자원, 건설/철거 비용.
- 저장 복원 코어: 사망자와 생존자 위치 중첩 허용, 살아 있는 주민 점유 충돌 거부, ID 유지, 명령 초기화.
- `Ashfall.Editor.Validation.Build`: Windows x64 개발용 빌드 성공.
- Unity Play 모드에서 안내 화면, 지형/주민 표시, P키 엎드리기, JSON 저장 및 불러오기 후 자세 유지·일시정지를 직접 확인.
- 독립 실행본 시작은 이 환경에서 `ShellExecuteW returned 5`로 거부되어, 실행본 자체의 입력/렌더링 검증은 미완료.

독립 .NET 테스트 EXE는 Windows 애플리케이션 제어 정책으로 실행이 차단되어,
같은 C# 검사를 설치된 Unity 에디터에서 실행했습니다. 보안 설정을 변경하지 않았습니다.

이 검사는 완전한 플레이 테스트나 장시간 성능 검증을 대신하지 않습니다.
